Política de privacidad

Última actualización: 10 de noviembre de 2026

Esta política describe cómo la aplicación interna “Ostin Batería – Asistente virtual” usa los datos de Google a los que se le da acceso.

Datos a los que accede

  • Google Sheets y Google Drive: archivos de horarios, productos, inventario y documentos de conocimiento del negocio, ubicados en carpetas designadas.
  • Google Calendar: los calendarios del negocio, para crear y leer eventos de entregas, recogidas, cierres y feriados.

Uso de los datos

Los datos se usan solo para el funcionamiento del asistente virtual y la gestión de pedidos de Ostin Batería. No se venden, no se usan para publicidad y no se comparten con terceros, salvo los proveedores técnicos necesarios para operar el servicio.

El uso de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Almacenamiento y seguridad

Los datos se procesan en servidores del negocio con acceso restringido a personal autorizado.

Revocar el acceso

Puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.
